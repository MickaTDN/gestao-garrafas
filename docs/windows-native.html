Gestão Vertente Aveludada

Abra a aplicação pelo atalho. O uso diário não necessita de administrador Windows.

Informática

Atualizações: execute o novo instalador autorizado. Forneça a chave e frase de recuperação para verificar o restauro antes das migrações. Nunca inicie código antigo depois de uma migração.

Recuperação: instale numa máquina isolada nova, usando a versão exata do backup. No assistente escolha recuperar. Confira identidade, sequência e histórico de entradas exportadas para Android antes de aprovar o arranque na manutenção.

O menu Manutenção cria backups cifrados e prepara o publicador HTTPS aprovado. Não altera firewall ou DNS. A chave privada de recuperação deve permanecer separada do computador e da frase.

Desinstalar conserva os dados e backups. Não apague cluster, WAL, chaves, backups ou o diário de manutenção para tentar resolver uma falha.

Os instaladores sintéticos não são distribuições de produção. A validação final Windows11/Android e a assinatura empresarial são obrigatórias.
